# Equal Website

A small static website for Equal, suitable for GitHub Pages.

## Files

- `index.html` — homepage
- `privacy.html` — privacy policy
- `style.css` — shared styles

## Before publishing

Replace these placeholders:

- `APP_STORE_URL` with the Equal App Store URL
- `SUPPORT_EMAIL` with your support email address
- `APP SCREENSHOT` with the actual app screenshot

The easiest way to add the screenshot is to put an image such as
`screenshot.png` in this folder and replace the `.phone-placeholder` element
in `index.html` with an `<img>` element.

## GitHub Pages

Create a GitHub repository, add these files, then enable GitHub Pages from
the repository's Settings → Pages. Publish from the branch containing these
files, using the repository root as the source.

No build system or static-site generator is required.
